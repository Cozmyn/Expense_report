## Cerințe nefuncționale / Non-functional requirements

Production TLS/encryption, ASVS validation, availability, disaster recovery, performance, end-to-end observability and accessibility acceptance remain deployment/test gates. See DEPLOYMENT.md and STATUS.md.

## Clarificări de acceptanță / Acceptance boundaries

Codul de infrastructură permite PostgreSQL, S3 privat, HTTPS în producție, hash-uri, scanare și păstrare legală; instalarea trebuie să configureze criptarea, permisiunile, certificatele, cheile, backup/PITR și colectarea de loguri/metrici/trace-uri. Disponibilitatea 99,9%, P95 sub 2 secunde, RPO/RTO și WCAG/ASVS necesită teste în mediul companiei. Nu sunt declarate certificate prin build-ul CI. Procesarea OCR este asincronă; importurile de până la 5 MB sunt previzualizate prin solicitări HTTP și au nevoie de măsurarea performanței pentru volumul real. Limitele de upload sunt configurabile; uploadul este multipart cu progres, fără protocol de reluare pe fragmente. Acesta devine necesar numai dacă infrastructura/volumele depășesc limitele aprobate.

Local OCR provides page/evidence and an explicit review state, with numeric confidence unset. It is assisted data entry. Receipts spanning several pages can be entered manually from the same original; automated grouping needs user review. Actual documents must be used to calibrate extraction acceptance. Browser tests use synthetic receipts and a real two-page PDF through real Tesseract/ClamAV; they do not establish accuracy on all supplier layouts.
